# Conway's Game of Life en Rust
En este repositorio se encuentra mi código para el laboratorio #2 de la clase de gráficas por computadora,
el cual se basaba en realizar el juego de la vida de Conway.

El código se puede ejecutar con `cargo run` desde la raíz y el output será lo que se puede ver [este gif](https://media.discordapp.net/attachments/830235530171645995/1530100244283523112/gifconway-ezgif.com-video-to-gif-converter1.gif?ex=6a645866&is=6a6306e6&hm=e18be9945ee772ca07946c5f6121de766f94f91137080ecd0190f0cf63be0893&=)
o bien si ese link no funciona, el gif también está en `./conway.gif`. También se puede tomar una captura del frame
actual con la tecla S, por si es deseado.
